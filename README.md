# Real Estate Stock Flow Simulator

## Description
The repository contains a python simulation of the Real Estate Stock Flow model proposed by DiPasquale and Wheaton.

In particular, the Stock Flow mode was introduced in [*The Markets for Real Estate Assets and Space: A Conceptual Framework*](https://onlinelibrary.wiley.com/doi/10.1111/1540-6229.00579), and provides a simple model by which one can determine the affect of various market perturbations on Total Housing Stock, Rent, Cost of Purchasing a House, and Construction.

## Usage
The code can be run via the command `python simulation.py` which will start an interactive window allowing the user to configure and run various simulations as they please.
